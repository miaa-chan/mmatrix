# m(iku)matrix
cmatrix but miku-fied, written in Python.

⚠️ This is NOT a fork of cmatrix nor does it use any of its code. This is merely a recreation.

## Install
Clone repository, change directory and run `make install`.
You can always update with `make update` when mmatrix gets an update.

## How to use
Run `mmatrix` on your terminal and enjoy :3
Pressing "+" increases its speed, "-" decreases it.
